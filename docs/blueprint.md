# **App Name**: Yuri's Devfolio

## Core Features:

- Hero Section Display: Showcase Yuri's name, professional title, and a compelling introduction in a full-width hero section, matching the reference's visual impact.
- Dynamic Projects Showcase: Display Yuri's development projects in a responsive grid layout, including project titles, descriptions, and imagery, similar to the reference's project section.
- Skills Section Integration: Clearly present Yuri's technical skills and proficiencies using a clean and structured layout as seen in the inspiration website.
- About Me Page: Dedicate a section for Yuri's professional background, experiences, and a brief personal narrative, maintaining the minimalist text-heavy design of the reference.
- Contact Form: Implement a functional and user-friendly contact form for visitors to connect with Yuri, preserving the subtle and professional styling of the original.
- Responsive Layout Adaptation: Ensure the entire website design and content flawlessly adjust and scale across all device types, from desktops to mobile phones, emulating the responsive behavior of the reference site.
- Subtle Page Animations: Incorporate subtle animations for element entrances (e.g., on scroll) and interactive hover states for links and buttons, replicating the smooth user experience of the inspiration website.

## Style Guidelines:

- A clean, light color scheme inspired by professionalism and clarity. The primary color is a deep, professional grey-blue (#52637A), suitable for headings and main elements. The background is an almost-white, cool grey (#F9FAFB) for maximum readability and a spacious feel. An accent color, a soft cyan-teal (#70C2BB), will be used sparingly for interactive elements or highlights to add a subtle pop.
- Body and headline font: 'Inter', a grotesque sans-serif that offers a modern, neutral, and highly readable aesthetic for both headlines and extended body text, aligning with the minimalist design.
- Utilize minimalistic line-art icons that complement the clean and modern aesthetic. Icons should be functional and visually understated, consistent with the reference site's use.
- Maintain a minimalist, spacious layout with ample white space around content blocks to enhance visual hierarchy and readability. Sections should be clearly delineated, and the content presented in a structured manner, resembling the reference's elegant, uncluttered presentation.
- Subtle and elegant animations will be implemented for page transitions, section reveals upon scrolling, and interactive elements. These animations will be smooth and unobtrusive, mirroring the understated interactivity of the reference website to improve user engagement without distraction.
